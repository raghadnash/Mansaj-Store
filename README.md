# متجر الملابس — تعليمات التشغيل والتعديل

مشروع واجهة متجر ملابس (Frontend-only) مبني بـ HTML/CSS/JS. ملفات المشروع الرئيسية:

- `index.html` — الصفحة الرئيسية.
- `css/style.css` — أنماط الموقع.
- `js/products.js` — بيانات المنتجات فقط (أضف/حرر المنتجات هنا).
- `js/app.js` — منطق العرض والتفاعل (الفلاتر، المودال، العربة).
- `images/` — صور المنتجات (SVG).

تشغيل محلي (مقترح):

1. افتح موجه الأوامر في مجلد المشروع `c:\Users\LENOVO\Desktop\qui`.
2. شغّل خادم محلي بسيط (يوصى به لعمل مسارات الصور بشكل صحيح):

```bash
python -m http.server 8000
# ثم افتح في المتصفح: http://localhost:8000/
```

بديل سريع (فتح الملف مباشرة): افتح `index.html` بالنقر المزدوج، لكن بعض المتصفحات قد تمنع تحميل موارد محلية — الأفضل استخدام الخادم.

كيفية إضافة منتج جديد:

1. افتح `js/products.js` وستجد مصفوفة `window.PRODUCTS`.
2. أضف كائناً جديداً بنفس شكل العناصر الموجودة (انظر التعليقات أعلى الملف). مثال موجز:

```js
{
  id: 'new1',
  title: 'اسم المنتج',
  category: 'dresses',
  price: 15000,
  images: ['../images/myimg.svg'],
  sizes: [{label:'S',inStock:true},{label:'M',inStock:true}],
  colors: [{label:'أحمر',hex:'#b1366b'}],
  description: 'وصف قصير'
}
```

3. ضع صورة المنتج داخل مجلد `images/` ثم استخدم المسار من `js/products.js` مثل `'../images/myimg.svg'`.
4. احفظ الملف وأعد تحميل الصفحة في المتصفح.

تنظيف العربة (localStorage):

إذا أردت مسح عربة التسوق من المتصفح، افتح أدوات المطور (F12) → Console ونفّذ:

```js
localStorage.removeItem('store_cart')
location.reload()
```

ملاحظات صيانة:
- احتفظ فقط ببيانات المنتجات داخل `js/products.js` لتسهيل التعديل بدون تغيير المنطق.
- إن رغبت بربط مع خادم/قاعدة بيانات لاحقاً، استبدل مصفوفة `PRODUCTS` بتحميل بيانات عبر `fetch()`.

إذا تحب، أستطيع:
- تحسين الواجهة البصرية أو إضافة صور واقعية أكثر.
- تصدير نسخة ZIP جاهزة للرفع.
